# Changelog

## [0.1.0] - Unreleased
### Added
- Custom dark WPF shell with sidebar navigation and status indicators.
- Overview dashboard, CPU, GPU, Memory and Storage pages with live rolling graphs.
- Central monitoring service with configurable polling interval and graceful "N/A" handling.
- JSON settings persisted in `%AppData%\BuiltByNyx\NyxMonitor\settings.json`.
- Unit tests for formatting, history buffers and settings.

### Not yet included
Network page, process manager, settings UI, system tray, theme/accent selection, launch at startup.
